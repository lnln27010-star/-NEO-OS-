# 数据中心资料导入与硬件更新调研

调研日期：2026-10-19。依据标准组织、设备厂商和 DCIM 厂商公开资料。本文给出工程接入建议，不将产品功能介绍当作市场占有率调查，也不承诺未经实际项目文件验证的识别率。

## 对本系统的判断

“数据中心信息”作为系统场景栏一级入口，与“全球能源网 / 园区 / 机房”并列。进入后，左侧选择具体中心，右侧维护中心概况、设备、线路、工况、冷却和校验。跨中心优化读取各中心保存的档案。

减少录入适合采用“结构化清册和模型建立档案、图纸补充和核对、运行接口持续更新”的组合。仅上传一张平面图，不能可靠得到完整电气网络、真实铭牌、实际负载、实时 CPU/GPU 配置或电价。

本轮页面调整只涉及导航层级。现有 CSV/JSON 资料导入和版本保存继续可用。下面的 IFC、CAD/PDF 解析、Redfish 自动发现与部件变更流程属于后续建议，尚未宣称已实现。

## 数据中心实际有哪些资料

| 资料 | 能提供的主要内容 | 需要注意 |
| --- | --- | --- |
| 园区总平面、建筑平面、机房布置及机柜列头图 | 建筑、房间、机柜编号、区域、通道、位置和尺寸 | 设计图与竣工图应分开；比例尺、单位、基点需核对 |
| 电气单线图、配电系统图、盘柜回路表、电缆清册 | 变压器—低压柜—UPS—母线—PDU—机柜关系，回路、容量、线缆规格 | 可见的连线和线色不足以自动确认电气连接；实际长度、敷设与修正系数需清册或现场资料 |
| 暖通系统图、P&ID、空调与液冷管路平面、设备选型表 | 冷水机、泵、CRAC、CDU、供回水回路及设计工况 | 原理图不等于真实空间管线；设计温度和流量不等于实测值 |
| 机柜 U 位图、服务器/BOM、资产或采购清单 | 服务器、GPU/CPU、内存、磁盘、网卡的型号、数量、安装位置、序列号 | 采购配置和当前运行配置可能已不同，需要运维核实 |
| 铭牌、厂家数据表、测试与调试报告 | 电压、容量、阻抗、效率、热设计、性能及测试值 | 不同型号和版本不能混用；具体工程计算需设备对应的参数 |
| 电费合同、分时电价表、表计与监控历史 | 电价、功率、电量、温度、流量、设备状态等工况 | 不应从建筑图纸推算；记录计量范围、采样周期、单位和时间 |

施耐德公开的参考设计说明包含 BOM、电气/机械单线图和 CAD 布局；这是判断设计资料组成的直接依据。[施耐德参考设计说明](https://blog.se.com/datacenter/2013/01/29/build-better-data-center-faster/)。其 AI 参考设计也将供配电、冷却、IT 空间作为配套设计内容。[参考设计 100](https://www.se.com/us/en/download/document/RD100DSR0_EN/)

## 常见数据接入方式与本项目优先级

| 路径 | 优先提取 | 自动化边界 | 建议顺序 |
| --- | --- | --- | --- |
| 设备清册、厂家明细、Excel/CSV、COBie | 设备、型号、厂家、空间归属、系统与序列号 | 先字段映射、统一单位、匹配编号，再导入预览；不同清册列名并不统一 | 第一批，最容易得到可校核的数据 |
| BIM/IFC；Revit 另导 IFC 与明细表 | 房间、设备实体、GlobalId、位置、尺寸、已有属性和显式端口关系 | 属性和连接必须在源模型中真实存在；几何模型不一定有完整工程参数 | 第一批，与清册按编号或 GlobalId 对齐 |
| DWG/DXF | 图层、块、块属性、文字标注、坐标、部分线路 | DWG 需合适的解析/转换环境；优先要求导出 DXF 或块属性表，普通线段不自动等于电气网络 | 第二批，针对实际项目制图规范适配 |
| 矢量 PDF | 可读取文字、表格、标注及作为审核底图 | 导出过程可能损失语义和精度；文字、符号和连线的归属需核对 | 第二批，提取候选项后人工确认 |
| 扫描 PDF、照片 | OCR 铭牌、文字与表格候选 | 图像识别不能保证设备归属、单位和连接正确，需显示页码/定位依据并复核 | 辅助录入 |
| Redfish/BMC 与资产系统；电表、BMS/EPMS 等接口 | 已发现的服务器/部件配置、状态及可提供的实时指标 | 每个厂商的实现覆盖不同；需资产编号、序列号与模型设备匹配，不自动覆盖人工确认值 | 持续更新配置与运行数据 |

COBie 针对可管理、可维护的建筑设备信息交付，适合把工程资料转为运维档案，不只交付一组可看的图。[NIBS COBie](https://nbims.nibs-wbdg.org/nbims/v3/cobie/)、[buildingSMART 设备维护交付](https://www.buildingsmart.org/fm-handover-equipment-maintenance/)

DCIM 厂商 Sunbird 的公开接入说明包含清册、已有 Visio/AutoCAD 平面图、现场资料、CMDB/API 集成和变更管理。这支持采用多来源汇总和人工核实的路径，不意味着任意图纸均能自动建立完整模型。[Sunbird 数据导入与接入服务](https://www.sunbirddcim.com/dcim-services)

Autodesk 文档明确区分 PDF 中的几何、文字和图像。扫描图像不会直接转为可编辑几何，PDF 输出还可能丢失信息。实际文件到手前，不给出“自动录入百分比”的承诺。[AutoCAD PDF 导入说明](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Core/files/GUID-F94D7059-5B4A-4396-97FE-765B1D037D56.htm)、[PDF 信息与精度限制](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-LT/files/GUID-1202CC8A-364F-4E93-8E86-6F476CD83C72.htm)

## 芯片是否要经常更换

机柜是承载结构，CPU/GPU 通常属于柜内服务器或计算托盘。应分别管理机柜、服务器与部件，不能把“机柜更新”和“芯片更新”合为一个动作。

硬件维护要区分故障更换和业务升级。CPU/GPU 并非按短周期例行更换的耗材；是否替换由健康情况、业务性能、能效、兼容性和厂商支持共同决定，不宜在系统内写死一个通用“芯片更换周期”。这也是本项目的资产管理建议，不是针对所有运营商的统计结论。

| 对象 | 合理的记录与维护粒度 |
| --- | --- |
| 机柜 | 编号、U 位、供电和冷却约束、位置；柜内服务器更换时保留机柜身份 |
| 通用 CPU 服务器 | 整机身份与配置；可更换 CPU、DIMM、磁盘、电源、网卡等须符合该型号服务手册 |
| PCIe GPU 服务器 | 以 GPU 板卡及插槽为部件粒度，核对供电、空间、散热和兼容清单 |
| SXM/高集成 AI 系统 | 按厂商定义的 GPU 模组、基板、托盘或整机 FRU 维护，不能默认现场任意替换裸芯片 |
| 液冷计算节点 | 部件变化需同时检查冷板、流量、供水温度、泄漏测试及供电约束；以具体厂家流程为准 |

Dell 的服务手册包含可拆卸处理器的具体步骤，说明部分平台允许部件级更换，但不是通用兼容承诺。[Dell PowerEdge C6615 处理器维护](https://www.dell.com/support/manuals/en-gb/poweredge-c6615/pec6615_ism_pub/removing-the-processor?guid=guid-a9e04067-b27f-4d3a-8975-eff8a71e107d&lang=en-us)

NVIDIA DGX B200 的公开客户可更换清单包含电源、风扇、存储、网卡和 DIMM 等，GPU 不在该清单中；其他部件需联系其支持。这是不能把所有 GPU 都建成“用户随时换一颗芯片”的具体例子。其维护后验证还包括系统测试。[NVIDIA DGX B200 服务说明](https://docs.nvidia.com/dgx/dgxb200-service-manual/introduction.html)

## 本系统下一阶段建议

1. 资料导入登记所属中心、专业、设计/竣工/运维阶段、图号、日期和版本，保留原文件与哈希。
2. 先做 Excel 清册映射和 IFC 属性提取，再对接实际项目 DWG/DXF 与 PDF；每次生成候选数据及差异预览。
3. 提取结果记录源文件、页码或 IFC GlobalId、原始值、单位和映射规则；待核实数据通过审核后进入正式修订，不能自动标成实测。
4. 加入“机柜 → 服务器/托盘 → 可更换部件”档案，记录型号、序列号、槽位/U 位、安装/退役、保修与更换原因，保留配置历史。
5. Redfish/资产接口发现配置变化后生成差异，与维护工单关联；监控时序单独保存，不把每次传感器变化都写成基础资料修订。[DMTF Redfish 属性与监测数据](https://redfish.dmtf.org/schemas/v1/DSP2053_2025.3.html)
6. 部件升级先检查机柜、PDU、UPS 与冷却余量；参数变化后使旧仿真结果失效，并用新负载重新求解。当前平台的版本保存与求解快照机制可以作为这部分基础。

要对实际图纸导入做可验证的实现，适合用一套同版本的 IFC/机房平面、电气单线图、设备及电缆清册作为样本，再确定字段映射和可自动提取的范围。参考设计只能用于开发验证，不能代替业主竣工资料。
