# 加载稳定性与性能修复

副本固定使用 `http://127.0.0.1:4186/`。启动脚本先构建，再启动优化预览；开发模式仍可使用 `npm run dev`。原项目的旧服务不被关闭或改写。

此次修复的加载问题包括重复安装同名图层、旧地图销毁后的异步回调、未完成初始化时切换投影，以及延迟加载样式将地图容器变成零高度。各场景的 Suspense 边界现已独立，加载新场景不会拆掉已有地图。

星空改用无损 WebP，保留原 PNG。提高了背景可见度，图片未加载完成时有备用星点；自定义层在绘制后恢复地图的 WebGL 状态。3D 深色模式中的“宇宙背景”开关独立保留。

园区高德 JS API 支持官方 `dark`（幻影黑）与 `darkblue`（极夜蓝）。能源网使用高德道路瓦片，并独立生成黑色、蓝黑色瓦片；这两种着色不冒充高德 JS API 的官方模板。顶部“深色底图风格”控制两处的对应选项。

官方主题说明：<https://lbs.amap.com/api/javascript-api-v2/guide/map/map-style/>。

## 实测传输体积

| 资源 | 原始文件字节 | 实际 gzip 传输字节 |
| --- | ---: | ---: |
| 电厂档案 | 9,181,057 | 885,884 |
| BIM 建筑 GLB | 2,836,844 | 220,468 |
| 中国省级边界 | 582,522 | 197,008 |

HTTP 测试确认解压后的 SHA256 与原文件一致，缓存校验返回 304。主入口由约 3.03 MB 拆为约 272 KB，其余代码按场景加载；272 KB 不代表全部场景的总代码量。

已打开场景保留资源与相机。隐藏的园区备用画布停止逐帧渲染；机房阴影贴图改为 2048，容量柱复用已排序的电厂数据，避免每次旋转重建大量瓦片对象。深色瓦片有内存和本机缓存。外部高德与 OSM 服务的首次请求仍受网络和服务端响应影响。
