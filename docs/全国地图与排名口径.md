# 全国选址地图与排名口径

## 地图及园区

- 底图使用项目已有的高德 JS API Key 与高德二维地图。NASA POWER 的 WGS84 省级代表点通过高德 `convertFrom` 转为 GCJ-02 后叠加。低缩放级别仅显示点位，高缩放级别显示省名与指标。
- 选中省份后可调用高德 `PlaceSearch` 搜索“产业园区”和“经济技术开发区”，单次展示最多 60 个返回 POI。POI 是地点检索结果，不是完整园区名录，也不证明土地、供电、通信、用水或数据中心准入条件。[高德地点搜索文档](https://lbs.amap.com/api/maps-javascript-api/reference/search/placesearch)
- 以园区 POI 创建项目时，项目保存园区名、POI ID、地址、GCJ-02 坐标；电网和地块核验状态仍为空。选址档案显示坐标系，避免与 WGS84 数据混用。[高德坐标转换说明](https://lbs.amap.com/api/javascript-api/guide/transform/convertfrom)
- 官方《中国开发区审核公告目录（2018年版）》与商务部后续评价可用于核对园区身份和政策背景，不能根据 POI 名称自动套用政策。[国家发改委目录公告](https://zfxxgk.ndrc.gov.cn/web/iteminfo.jsp?id=14156)、[商务部 2025 年评价发布](https://www.mofcom.gov.cn/syxwfb/art/2026/art_d23a363c87f6452bac1c6a3930340f67.html)

## 指标来源

| 地图维度 | 系统使用的资料 | 解释范围 |
| --- | --- | --- |
| 代理购电 | 本地导入快照，最新 2026-08 | 省级历史价格参考，不是项目综合到户价；地区、电压、基本电费和交易合同需要另核 |
| 现货 | 本地日/小时价格快照 | 只在展开的历史详情内展示；不是用户最终结算价 |
| 风光与夏季气候 | NASA POWER 2001—2025 省级代表点 | 点位气候，不是省域平均值或具体地块可开发装机量 |
| 算力需求 | 企业导入合同、RFP 和线索，按阶段分开 | 没有导入资料的省份标为缺证据；不从产业园区或人口推断签约量 |
| 政策 | 国家算力网、绿色低碳文件与已整理地方政策原文 | 枢纽身份不是项目审批或补贴资格；城市/园区适用性需另核 |
| 电网、土地、水、网络与韧性 | 用户导入的项目侧区域证据 | 仅带来源和状态的城市/园区资料参与硬边界；省级公开资料不视为可接入意见 |

## 排序

页面有综合参考、经济性、需求、风光气候和落地证据五种排序。经济性目前使用代理购电历史价格的相对位次；项目实际 IRR/NPV 在建立项目并完成投资测算后查看。风光气候分量分别为太阳辐照 45%、50 米风速 35%、夏季气温 20%，只用于区域参考。需求仅来自已导入合同 MW。落地证据来自电网、土地、水、网络、政策、风险六类项目资料。

综合权重默认经济性 35、需求 30、资源 15、落地证据 20，可在页面调整。四类数据齐全且无否决项时才显示完整综合分；有缺项的地区显示“参考”及 `已覆盖维度/4`，先按数据覆盖度、再按已有维度得分排序，不输出正式建设推荐。用户可按已核实接入 MW 和实测时延筛选；省级价格低不能越过项目级硬条件。

园区 POI 没有可比的公开供电与客户数据，默认只显示候选地点。创建园区项目后，按已保存项目的尽调完成度和可计算的项目财务结果展示，尚未建立项目的 POI 不计算园区投资分数。
