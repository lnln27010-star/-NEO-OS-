# NEO OS 功能架构适配说明

本轮以用户提供的《分布式AIDC算电协同操作系统 NEO OS 总体规划方案》为功能依据。系统保留现有 React、WebGL 和 FastAPI 实现，重组业务入口和数据关系。方案的技术原则强调模块化、开放接口与可替换，因而没有为了选型表中的 Vue 3 重写现有场景。

## 跨页面智能操作

顶部“智能操作”提供受控任务。它读取当前业务中心和用户选择的基地，可以查询已登记中心的缺项、最近任务，或向任务服务提交 pandapower 供电校核和 PyPSA 多站优化。任务状态与结果来自实际任务记录。输入只能匹配定义好的任务类型，不能执行任意命令；外部大语言模型未接入。基本信息、专业求解与任务记录之间以基地 ID 和基线版本关联。

## 数据与状态约定

基本信息中的草稿修订、服务器配置修订与发布基线继续分开。`/api/platform/overview` 汇总已登记、已发布和已导入测点的基地，不生成演示遥测。`/api/platform/capabilities` 读取当前求解环境。`/api/platform/designs` 在服务端重算并保存方案估算，不接受浏览器传入的伪造结果。`/api/platform/assistant/tasks` 只接受四种确定任务，专业求解仍经过已有输入校验和任务队列。

用户原先已保存的中心、设备、电缆、版本和求解任务未迁移或清空。旧的本机规划站点与快速调度仍作为场景假设保留；它们不会自动变为正式基地数据。外部系统接入、跨基地边缘节点、事件总线、统一身份和现场策略控制，需要相应系统的接口资料、访问授权和实施环境，目前页面明确显示接入状态。
