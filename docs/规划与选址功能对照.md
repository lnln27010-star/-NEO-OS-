# 规划与选址中心：原功能清单与实际落地

| 原功能 | 页面与实际动作 | 数据来源及边界 |
| --- | --- | --- |
| 全国需求地图 | 全国机会研判：高德底图叠加省级指标；省级已导入合同 MW、区域证据矩阵；客户与开发页按推理、训练、通算、存储、灾备、边缘拆分逐客户需求 | 本企业导入的需求证据；没有真实客户资料时显示无证据，不把市场供给当订单 |
| 电价地图与到户价 | 全国指标地图查看代理购电及现货历史；投资测算将电能量、输配、线损、系统费用、基金、绿电及峰谷占比拆开 | 历史价格快照不是最新项目报价；到户结算分项需项目合同或正式报价 |
| 风光、气候、水土地资源 | 高德地图可切换风光指标；区域证据矩阵接收城市级水、土地、风光资料；场址尽调记录具体可用面积、权属、供排水等 | 气候代表点不能替代地块资源；未收到业主或主管单位资料前显示待核实 |
| 政策与准入 | 全国区域栏链接国家及已收录地方政策原文，区域证据导入具体适用结论与文件依据，场址关口记录审批状态 | 政策覆盖省份不等于该项目获得许可或补贴 |
| 网络与客户圈层 | 客户需求逐条保存时延、SLA、可迁移比例；城市/场址记录双运营商、独立路由、P99 实测时延；区域硬条件筛选 | 目前没有运营商实时网络拓扑或实测接口，需导入证据 |
| 硬条件初筛 | 全国机会页按接入 MW、时延、已核实关口筛选，证据不全标记“不足”；项目页显示投决缺项 | 不合成主观总分；没有资料不自动判定通过 |
| 项目机会池 | 七步开发漏斗、客户/RFP/意向/线索分账、里程碑责任人和阻塞、项目版本 | 项目数据由用户维护并保存至本机后端 |
| 场址尽调 | 地块、电力双路、接入成本、土地荷载、水冷却、双运营商、环境风险；七关口证据附件 | 状态由团队标注，文件来源仍需人工核验 |
| 技术方案比选 | 多套供电冗余、冷却、液冷比、机柜密度、PUE、CAPEX 和交期并排比较；分期投资分项 | 方案级预估；物理拓扑、气流和设备价格需工程校核 |
| 投资测算 | 按月的分期 CAPEX、租赁/GPU 收入、电费、OPEX、融资、NPV/IRR、敏感性、CSV 导出 | 财务规划模型，未纳入完整税制、残值与逐时季节性运行 |
| 组合决策 | 勾选多个项目汇总资金和现金流；新客户 IT 需求按接入余量、时延和边际电费试分配 | 尚无网络费用、客户迁移合同和资金约束的正式优化 |

## 当前需要真实资料才能完成的业务判断

1. 各城市供电公司接入意见及可供容量、独立路径和投产日期。
2. 地块权属、消防和荷载资料，以及供排水和环境限制。
3. 目标客户合同或招标文件、交付日期、SLA、报价与工作负载。
4. 运营商路由、带宽报价和客户点到点实测时延。
5. 项目电力合同的完整结算构成、设备报价与融资条件。

上述资料未取得时，页面展示“待核实”与方案假设。不能将该状态的区域或项目输出为正式投资推荐。
