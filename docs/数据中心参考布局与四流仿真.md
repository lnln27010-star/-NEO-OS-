# 数据中心参考布局与四流仿真 v3

本版使用项目原有 96 × 61m 合成建筑外壳，按真实数据中心的布置原则构造参考方案。设备、容量和坐标为可调整的示例配置，不是业主竣工 BIM 或厂家认证选型。

## 调研依据

- [NVIDIA DGX SuperPOD 冷却与气流设计](https://docs.nvidia.com/dgx-superpod/design-guides/dgx-superpod-data-center-design-h100/latest/cooling.html)：机柜前对前形成冷通道，背对背形成热通道；通道需支持维护和设备运输。本版冷通道设计宽度约 2.4m、热通道约 1.2m，并建立透明围护。原 IFC 结构柱保留，机柜和泵位避让柱网及保护间距。
- [NVIDIA DSX 设施参考架构](https://docs.nvidia.com/dsx/facilities-infra/reference-design-overview)：参考数据厅、机电廊道、供电设施和网络核心的功能分区关系。
- [Vertiv CDU 技术说明](https://www.vertiv.com/en-latam/insights/articles/educational-articles/understanding-coolant-distribution-units-cdus-for-liquid-cooling/)：区分设施水回路和 CDU 的机柜侧二次回路。

引用用于通道、分区和回路设计原则，未照搬这些资料的设备容量配置。

## 布局与设备

四个数据厅模块，每厅 96 柜：北侧两个风冷厅，南侧两个液冷背板厅。中间布置网络核心、运维通道和冷水机组；东侧按 A 路供配电间、泵房、B 路供配电间组织。室外配置冷却塔、部分冷水机组及备用发电机，停车区移至西侧外围。保留冷热通道、检修廊道和运输走道。

## 操作

进入「机房」默认打开俯视布局并启用直接拖动，详情面板默认收起。

1. 按住设备主体左键拖动，放开后按 5cm 网格落位。右键用于视角操作。
2. 密排机柜拖到邻柜中心附近可以交换位置。越界、重叠时显示红色预览并保留原位置。
3. 点击设备打开工作台，可定位、旋转、拆卸、启停或修改模拟额定参数。
4. 拆卸后出现在设备库，可拖入场景安装，也可点击「点击空地安装」后选择位置。Esc 取消放置。
5. 服务器支持抽出、推入、拆装和跨柜空槽移装。抽出时打开机柜门并退出运行；推入恢复。
6. 操作支持撤销，布局自动保存到 v3 本机存储；JSON 导入先验证，再整体应用，错误不会破坏当前布局。

旧 v2 布局文件可迁移同名设备的装配、启停及连接状态，坐标按新的分区布局重排。旧 v2 本机存储保留，不覆盖。新增主管节点使用新参考位置。

## 四类流动

底部图标工具栏提供俯视、三维总览、建筑外观、机房通道、拖动、自动对齐、设备名称、四流和暂停。上方显示运行指标，右侧设备属性与运行面板共享位置。建筑外观保留实体外墙和屋顶，室内模式保留透视外墙。

- 电力：变压器 → 低压柜 → UPS 模块 → A / B 母线 → 汇流柜 → 列 PDU → 机柜；另有机械供电、电池放电和备用发电路径。
- 水：冷冻水供回水、冷却水供回水、CDU 二次供回水分别显示。并联泵通过吸水和排水总管分流，冷却塔具有独立进水总管。
- 热 / 风：冷通道送风、热通道回风，以及液冷背板捕获热量后的余热；方向依据机柜朝向。
- 信息：核心 / 共享服务 → 数据厅 ToR → 服务器，同时显示虚拟 BMS 设备状态监测通道。

设备移动后路径跟随端点；安装、断电、断网、阀门及回路状态改变时更新流量和动画。停用或缺失的设备不会继续出现有效运行流动。动画用于方向展示，速度经过视觉缩放；连线表示功能关系，不是施工深化管线图。

## 运行计算与适用范围

支持正常运行、CDU 降流、列 PDU 断开、网络中断、UPS A 路失电，提供 120 秒时间轴、2× 播放、暂停、告警定位和完整 JSON 结果导出。

- 风冷柜与液冷柜采用独立功率参数，装配数量、抽出状态和网络状态进入功率计算。
- 风冷柜热量由精密空调承担；背板液冷柜按最多 90% 捕获分配水侧热量，并受 CDU 额定换热容量限制。
- 水侧采用 `Q = ṁ × 4.186 × ΔT`，水密度近似 1kg/L。冷冻水设计温差 6°C、冷却水 5°C。
- 泵功率采用示例扬程 35m、效率 0.75；CDU 二次泵采用 25m、效率 0.7。制冷机示例 COP 为 5.5。
- 设施功率汇总 IT、冷机、风机、水泵、CDU、网络和 UPS 损耗，不再只使用固定 PUE 倍率。
- 双路供电、UPS 电池能量桥接及备用发电条件进入可用性计算。容量超限产生设备告警，尚未求解断路器选择性与完整电气暂态。
- 机柜槽位和设备状态改变后即时更新供电与网络状态，温度保留连续性。NB-OPS-4.0 按 1 秒步长积分一次水、二次水、房间热容量和电池能量；传感器采用 12 秒一阶响应。尚未进行空间 CFD、完整压降网络、厂家性能曲线或现场遥测校准。

可用于布置交互、配置比较和故障推演。容量、气候、设备曲线及几何条件应按实际项目进一步标定，不能把本版输出视为现场实测。

## NB-OPS-4.0 交互与动态模型

- 选中设备保留青色轮廓、半透明体积和地面标识。拖动时显示目标体积、局部网格及磁吸对齐线；有效落位为青色、碰撞为红色、机柜互换为金色。同类设备中心轴在 0.24m 范围内磁吸，Shift 临时取消磁吸，基础坐标精度为 0.05m。点击安装与设备库拖入使用同一落位判定。
- 设备名称使用单纹理图集、单绘制批次。按距离和选中优先级分级显示，远景最多 14 个标签，窄窗口进一步减少。标签进行屏幕碰撞避让，并预留指标、侧栏与工具栏区域。
- 默认一次水等效容积 20m³、每个 CDU 二次回路 2m³、每厅等效热容量 14MJ/K、室内设定温度 24°C。设备容量、有效流量与换热温差共同限制实际除热量；供回水和机柜温度连续演化。CDU 与机柜距离增加时，采用简化等效长度系数折减流量；机柜离开冷通道、反向放置时增加局部回流惩罚。这些参数是可调模型假设，必须按具体建筑和设备校准。
- UPS 按供电母线的实际功率逐秒扣减 kWh，恢复供电后限功率回充。备用发电启动延迟从本次市电中断开始计时，不使用整个仿真开始时间。
- 负载、参数、移动、安装、启停等变更记录为带时间戳事件。时间轴回放与 JSON 导出使用真实事件序列，设备操作不会把过去全部改写为当前布置。
- 回归补充：磁吸与 Shift 绕过、运行途中停冷的温度连续性、温升与恢复制冷、事件回放一致性、运行途中断电后的发电延迟和电池能量变化。编译、生产构建和浏览器实测均通过。

## NB-OPS-5.0 自定义布局与端口接线

本版从固定参考资产列表改为按当前布局生成机柜与配电回路；新增资产、删除资产、重新接线均进入运行、四流、时间轴事件及导出记录。原有参考布局仍作为初始方案。

1. 设备库支持 17 类模型，包括风冷和液冷背板机柜、配电、UPS、电池、网络、液冷、冷机、水泵、冷却塔、发电机、主管及母线。供配电设备可指定 A/B 路，新机柜默认满配 42U。
2. 新设备先进入待安装状态，点击空地落位；柱网、建筑边界及设备碰撞进入落位验证。新设备的端口默认不连接，不会自动成为有效供电或冷却设备。
3. 单击设备只选中。选择「移动设备」后才允许拖动选中设备，X/Z 箭头锁定方向，侧栏提供 5cm、25cm、1m 步进推动。Esc 结束移动。拖动保留原位置高亮和目标预览。
4. 接线页列出与设备类型匹配的上游，可断开电源、供回水、网络端口。电源和网络上联拒绝循环连接。液冷机柜的供回水按同一 CDU 成对更新；设备状态及水流参与可用性判定。
5. 删除设备会移出模型及仿真，清除下游对该设备的端口引用，可撤销。删除记录保留于布局文件中用于撤销及兼容迁移，不在设备列表显示。JSON 布局升级为 v4，继续读取 v2/v3；自定义设备与接线一起保存。旧本机存储键沿用，避免丢失用户布局。
6. 机身铭牌贴附于设备前侧，远景不再展示每台设备的悬浮卡片，仅保留数据厅、供配电、水泵和网络区域总牌。实体外墙默认不透明，外墙透视由独立开关控制；内部视点可移除屋顶以观察设备。

仿真仍是集中参数热模型与稳态可用性、电量模型。当前供配电按 A/B 系统聚合，设备容量超限告警，不自动求解保护选择性或逐支路电压降；冷站按并联设备容量及供回水连接是否有效计算，未求解完整管网压力、阀门 Cv 或四端口冷机性能曲线。可用于自定义配置、连接中断与故障推演，工程设计仍应结合厂家曲线与实际设施参数校准。备用发电与 ATS 接管采用系统级延时逻辑。

新增回归覆盖 17 类设备创建、自定义机柜接线后运行、双路供电断开、成对液冷连接、网络链路传播及循环拒绝、删除/撤销、v4 导入导出、删除全部机柜时空场景安全、未接线 UPS 不得绕过供电、自定义母线替换、A/B 路创建、未接线泵不计入运行。

## v5.1 页面交付与版本识别

主页面顶部提供新增设备、设备接线、移动设备和运行仿真的文字入口；标题显示「工作台 · v5.1」，便于识别已更新页面。入口分别打开设备库、端口接线、移动操作及运行设置。

此前多标签页长期运行已加载的旧脚本，构建更新不会自动替换已有 JavaScript 会话。生产首页现采用 no-store，构建写入 build-version.json，/__project 返回当前构建标识。客户端每 15 秒及窗口恢复焦点时核对版本；未处于设备拖动、放置或表单输入时刷新到当前构建。设备布局持久化保留。全局地图与机房旧会话已刷新，服务路径为 D:/算电协同平台/算电协同 2 - 副本，端口 4186。
