# DSX 交互调研与本产品适配

2026-11-02 查阅 NVIDIA 官方 [DSX Blueprint 产品说明](https://build.nvidia.com/nvidia/omniverse-dsx-blueprint-for-ai-factories/blueprintcard)、[用户界面导览](https://docs.omniverse.nvidia.com/dsx/latest/user-interface-walkthrough.html) 与 [架构说明](https://docs.omniverse.nvidia.com/dsx/latest/system-architecture.html)。这里参考其交互组织，不声称本产品使用 NVIDIA Omniverse Kit、OpenUSD、DSX Air 或 NVIDIA 的求解服务。

[DSX 平台文档](https://docs.nvidia.com/dsx/)把 Omniverse DSX Blueprint 的物理设施孪生和 [DSX Air](https://docs.nvidia.com/dsx-air) 的 IT 与网络逻辑仿真列为不同能力。本产品目前以地球、园区、机房、电力和制冷为主，因此重点参考物理孪生的交互方式；不能把现有三维机房称为已接入 DSX Air。

## 对用户有用的设计规律

1. 进入产品直接看到可交互的全局地球。选中基地后，场景视角与基地分析联动；配置、分析、仿真是同一场景的上下文工具。
2. 从基地进入设施与设备层级。视角预设可把操作者带回总览、机房、制冷和供电等已知位置。
3. 仿真输入、执行、结果可视化和数值证据在当前场景中关联。热、电两类测试有不同的参数和图例。
4. 官方 Blueprint 的部分 KPI 和成本是前端硬编码演示值，热图与分析 KPI 也没有自动联动。它是开发参考，不是现成生产系统。因此本产品不能照搬这些数值当作真实运营数据。

## 本轮实现

- 移除独立的静态驾驶舱入口。现有全球能源网成为全域算电驾驶舱，保留 2D/3D、旋转地球、底图、网架、能源图层和电价分析；园区与机房仍由空间层级进入。
- 在全球场景加入按需展开的基地与运行面板：登记、发布、测点和正式计算数量；基地列表、容量与资料来源；打开基本信息。真实基地仅在基础资料有有效经纬度时绘制点并允许定位。
- 场景中所选基地作为本机工作上下文，工程设计、专业运营、人工运维和智能操作打开时优先选它；各页面仍可手动调整。
- 价格或设施分析打开时，基地面板自动收成窄条，避免遮盖地图分析。可从窄条返回基地面板。
- 导航中的其他工作中心返回全域场景，而非直接跳到机房。旧 `?center=dashboard` 链接由默认路由导向全域场景。
- 规划、工程、运营和运维各自改为两种明确的工作模式，场景推演与需资料依据的专业计算、人工事件分开呈现，不再把两套表单和结果长页堆叠。

## 仍需具备的条件

Meta42/ECC/DCIM 的实时遥测、现场设备写入、Omniverse/OpenUSD 资产管线、企业认证和审批均未接入。图纸、设备铭牌、校准数据与基线应先在“基本信息”确认；实际工程计算可通过现有求解任务运行。已登记基地没有坐标时，不能把示意园区位置伪装成真实位置。
