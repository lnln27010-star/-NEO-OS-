# 基本信息：按运营流程维护

入口在系统一级场景栏“全球能源网 / 园区 / 机房 / 基本信息”。新增工作区位于基本信息内；全域驾驶舱与数字孪生合为一个入口，其余工作中心见 [功能架构适配说明](NEO-OS功能架构适配.md)。

## 工作区

| 分组 | 页面与用途 |
| --- | --- |
| 基础档案 | 中心概况、空间与机柜、设备台账、连接关系、冷却边界。维护楼栋/楼层/机房、机柜 U 容量、铭牌、电缆和供回水/网络连接 |
| 运营维护 | 服务器与部件、资料与导入、配置变更、运行数据、工况与电价。物理配置、原始资料、操作记录和测量数据分开保存 |
| 数据治理 | 数据质量、版本与审计。查看缺项、冲突、导入来源、变更前后内容和发布记录 |

每个中心独立存储。现有 540 台模型资产保留，未自动生成真实服务器/GPU 身份，也未自动发布为实测基线。新建中心的容量、PUE、储能等未知参数留空；确认没有的光伏/储能由维护者明确填零。

## 草稿与生效基线

保存草稿生成档案修订 r；服务器/部件维护生成配置修订 c。发布时填写校核人、适用范围和待完善内容，冻结档案与配置，生成生效基线 B。操作人是本地登记信息，未引入账号鉴权或多人审批。

正式工程求解选择已发布的中心基线。新草稿和新配置不会改写既有基线与历史任务。发布不代表参数均已通过现场认证，来源和缺项继续保留；求解时仍检查必需的电气、负载和工况参数，不使用模型默认值补齐。

“当前三维模型与临时参数”仍用于原有推演，与正式基线分开。资料维护不会自动改写三维机房。OpenFOAM/FEniCSx 本机运行环境仍待配置，未新增其数值验证。

## 图纸和清册导入

1. 先保存所属中心，登记资料标题、专业、设计/竣工/运营阶段、图号、版本、提供单位和日期。
2. 上传后保留原文件、时间和 SHA-256，在独立进程提取。单文件上限 40 MB，解析最长 60 秒，最多两个解析进程，排队受限。失败可重新解析。
3. 选择提取表与目标档案，核对字段、数值倍率和固定值。中文设备类型、部件类别、安装状态和 A/B 端口按字典转换，不按外观或邻近位置猜连接。
4. 预览更新编号、字段及原值/新值。先修正错误；同编号合并，不自动删除源表缺少的已有记录。
5. 校核后导入草稿或配置，保留文件指纹、表名、行号及可取得的页码/IFC GlobalId。发布后才用于正式求解。

支持范围：

- CSV/XLSX：数据表，表头应明确单位。公式只读已保存的缓存值，不执行公式或宏。
- IFC：识别到的机电对象、已有属性、显式空间/端口关系和可取得的位置。不从几何邻近推断接线。新设备需明确容量，新机柜需明确 U 容量。
- DXF：模型空间的块属性、文字和坐标，单位明确时换算为米。不自动解释普通线段的电气拓扑。
- PDF：可读取文字和规则表格，保留页码；不是通用工程图符号识别或 OCR。
- JSON：记录数组、rows 数组或 Redfish 离线快照包。快照包格式为 system 对象与 processors、memory、drives、network 数组。只读取文件已有资源，不访问 @odata 网络链接。
- DWG、PNG/JPG、扫描 PDF：保留原件，不冒充已完成结构化识别。DWG 可另导 DXF/IFC；扫描件需人工资料或后续 OCR。

额定容量单位按设备类型分别为 kW、kWh、m³/h 或 Gb/s。电气铭牌另维护 kVA、电压、电流、功率因数。配电柜、UPS、PDU 和母线可按明确的额定电流或 kVA 校核。只有给定 kVA 与功率因数，或电流、电压和功率因数，才会计算有功容量，不套用默认功率因数。

设备位置采用机房局部米制坐标，地理大坐标不能直接使用，超界要求处理，不自动截断。位置核实标记在设备台账维护。

## 服务器、部件和变更

机柜保持稳定编号。服务器/计算托盘记录机柜、U 位、型号、序列号、状态和保修；CPU、GPU、内存、磁盘、网卡、电源独立记录服务器、槽位、额定/TDP、容量、接口与序列号，另有在库、待定位、在位、维修和退役状态。

额定/TDP 与实测功率分开，不能相加冒充实际功率。正式计算优先用机柜工况或实测值；缺失时，只有关联在位服务器都有实测功率，才可汇总这些服务器的实测值。

替换部件、安装/拆卸和移位按以下流程登记：

1. 建立计划，填写目标、备件或目标位置、维护窗口、原因和登记人。
2. 校验类别、库存、服务器身份、U 位和槽位冲突，保存计划时的配置修订。
3. 现场完成后确认实际操作、机型兼容性与维护后验证，再登记完成。此功能不控制现场硬件，不自动保证厂商兼容性。
4. 原部件进入在库或维修，新部件继承槽位，保留前后配置。计划后配置被改动、重复完成会拒绝登记。
5. 部件变更清除该服务器当前实测功率。相关机柜的旧功率和曲线留在历史修订，当前草稿等待复测；再发布新基线，避免沿用旧工况。

## 运行数据

当前支持离线导入，尚未连接现场实时采集。测点字段为 timestamp、target_id、metric、value。已有中心/设备/服务器编号可作为目标，中心总表使用 center。无偏移的时间按中心维护的 IANA 时区解释。

it_kw、solar_kw、facility_kw 使用 kW；power_w 使用 W；temperature_c 使用 °C；flow_lpm 使用 L/min。同源、同时间、同目标和同指标不重复增加记录。

选择来源和本地日期，可按小时生成 center 对象的 IT/光伏工况。当前为已提供样本的算术平均，不是按间隔积分的电量。无样本保持空白；应用到草稿仅更新有样本的小时并保留电价。其他设备测点保留原始记录，不自动重复汇总成中心总量。

## 保存与验证

数据库位于 `.solver-data/foundation.sqlite3`，原文件位于 `.solver-data/documents/`。升级前一致性备份位于 `.solver-data/backups/foundation-before-operations-20261019.sqlite3`。迁移时同时备份数据库和原文件。

测试覆盖 IFC/DXF/PDF/XLSX/CSV/Redfish 快照解析、导入差异、并发修订、槽位约束、功率复测、基线冻结、跨时区工况和真实 pandapower 求解。页面端到端测试使用隔离临时数据库，不向现有中心写入测试服务器、GPU 或文件。
