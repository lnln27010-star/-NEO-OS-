## 资料范围

| 分类 | 维护内容 |
| --- | --- |
| 中心概况 | 编码、名称、地区、地址、运营单位、经纬度、资料日期与依据；IT/购电容量、PUE、光伏、储能、上级电网短路容量 |
| 设备台账 | 类型、厂家、型号、序列号、所在房间、安装启用、坐标；额定容量、实际功率、功率因数；变压器 kVA、电压、阻抗、空载参数；UPS 损耗；风/水发热及流量 |
| 线路与接线 | 线路编号、两端设备、下游 A/B/供回水/网络端口；电缆规格、材质、截面、芯数、敷设、实际长度、电阻、电抗、载流量、并联数、投运状态 |
| 电价与负载 | 各中心本地时间 0–23 时的电价、IT 总负载和光伏出力；各设备独立 24 小时负载曲线 |
| 冷却与热工 | 房间尺寸、送风和水侧工况、液冷捕热比例、材料导热与换热系数 |
| 数据校验 | 重号、失效接线端点、自连接、重复端口、供电环路、光伏超容量，以及缺失铭牌、负载、线路参数 |

数据来源分为“模型待核实”“人工录入”“现场实测”。来源是人工维护的资料标记，不是系统自动核实结论。空白值保持空白，不自动变成实测零值。

## 保存、导入与修订

- 每个中心独立保存到求解服务的 `.solver-data/foundation.sqlite3`，同一本机服务的浏览器均可读取，不再依赖浏览器 localStorage 保存工程资料。停用服务不会删除数据库；迁移部署时一并备份该文件。
- “保存资料”提交当前中心的全部草稿，生成修订编号。保存校验拒绝错误，允许保留不完整资料；提交求解时仍检查必需参数。多窗口修改采用修订冲突检查，冲突后保留本窗口草稿，需重新读取后合并。
- 每个中心保留最近 30 个修订。读取历史修订只更新草稿，再保存才生效。归档可恢复，归档中心不能用于新求解任务。
- 设备、线路和逐时曲线支持 UTF-8 CSV 模板、导入预览、同编号合并更新及导出。导入文件内的重复设备/线路编号会拒绝。CSV 使用模板英文列名；单位对应页面字段。中心级曲线列为 `hour,price,it_kw,solar_kw`，设备曲线为 `hour,load_kw`，小时为不重复的 0–23。
- JSON 资料包包含全部维护数据。导入至当前中心时保留当前中心内部 ID，资料包其余内容替换草稿；设备/线路 CSV 则按编号合并。应用预览后仍需手动保存。
- “从当前机房同步”带入现有设备和连接，新记录标为模型待核实；保留已维护的厂家、铭牌、实际负载、电缆及实际容量。机房坐标、安装状态会随本次同步更新。不会凭渲染位置生成“实测电缆长度”。

## 与工程求解的关系

在工程求解中将“计算数据来源”切换为“已维护的数据中心资料”。pandapower 选择一个中心和工况小时；PyPSA 可勾选多个中心。

- pandapower 使用逐台变压器铭牌、设备功率因数、UPS 损耗、维护的供电连接和逐根电缆长度/R/X/载流量/并联数。指定小时的设备曲线优先于固定功率。必需参数缺失会拒绝提交，不以三维模型默认参数补齐。这里仍是稳态等效计算，没有新增开关暂态和保护选择性计算。
- PyPSA 使用每个中心独立的逐小时电价、IT 负载和光伏曲线，以及中心容量、PUE、储能功率/容量；不再把各中心基准负载等分。运行策略中的可迁移比例、迁移成本、总购电上限、SOC 下限继续由任务配置。储能效率目前仍为各 95%，首末 SOC 为 50%。
- OpenFOAM/FEniCSx 接收保存的风水温度、速度、换热系数与设备热量等适配字段。OpenFOAM 空间资料的尺寸已保存，但当前房间求解域仍为既有 96×61×8.5m 标准域；没有在本次维护页面工作中宣称完成任意厂房 CFD 几何。两个 Linux 引擎本机仍待配置，未执行数值验证。
- 保存的中心资料只作为工程数据源，不会自动改写当前三维机房布局。资料求解结果按中心和修订在表格/文件中查看，不自动覆盖当前三维场景的结果图层，以免同编号设备对应到错误中心。
- 服务端在提交时冻结所选中心的修订、数据 SHA-256 和完整编译输入，保存到每个任务目录。后续修改资料不会改变历史任务。MCP 的 submit_simulation / prepare_simulation_case 新增可选 data_center_ids 和 data_hour，仍兼容原先 7 个工具。

## 校验

`python -m unittest backend.tests.test_service backend.tests.test_foundation -v` 验证原有求解服务、数据库重读、中心隔离、修订冲突、历史回看、归档与缺参拒绝，以及真实潮流对电缆长度变化的响应、真实多站点优化对各中心逐时数据的使用。`node scripts/test-foundation.mjs` 验证 CSV 与同步现有模型时对人工资料的保留。
