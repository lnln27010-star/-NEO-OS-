# 规划与选址中心：投前工作台

## 工作顺序

1. **全国机会研判**：以全国省市证据矩阵为入口，按接入容量、时延与资料状态筛选；查看电价、风光、气候、政策、合同需求，并批量导入具体项目证据。旧省级指标地图保留在下方。
2. **项目机会池**：七步开发漏斗，按阶段和客户证据筛选项目；显示阻塞事项、下一节点、客户需求结构与投决缺项。
3. **客户与开发**：一项目多客户需求，按推理、训练、通算、存储、灾备和边缘拆分，维护客户所在地、容量、交付日、SLA、带宽、时延、可迁移比例、目标价格、合同/RFP依据；商业模式区分托管、容量租赁、GPU服务、自用和混合经营。七步里程碑分别维护责任人、计划、实际和阻塞。
4. **场址尽调**：具体地块、双路电力、接入费、权属荷载、取排水、双运营商和环境风险。七类关口分别标注待获取、假设、报价、已核实、不满足。已核实必须填写资料依据；项目保存后可上传附件。
5. **技术方案**：分期容量、建设月数、投产月和 CAPEX 分项；可维护多套供配电和冷却备选架构并比较设施功率、年用电、投资与交期。
6. **投资测算**：采用[IDC 工作簿口径](IDC工作簿投资测算适配.md)，支持导入四期假设、两档机柜、月末上架节奏、比例或逐项 OPEX、设备更换、税费与杠杆；输出逐年利润、现金流、IRR、NPV、实时敏感性和 CSV。
7. **组合决策**：勾选多个项目汇总 CAPEX 与现金流，按接入余量、实测时延及边际电费试分配新客户负载。

逐项对应关系和未取得资料的边界见 [规划与选址功能对照](规划与选址功能对照.md)。

## 数据与计算边界

- 项目档案保存在 `.solver-data/planning.sqlite3`，附件保存在 `.solver-data/planning-documents`。前端不向真实客户系统、电网或交易平台同步数据。
- 每次保存生成不可变的项目输入版本；项目页可导出历史版本，避免参数变化后无法还原旧测算依据。版本记录不等于正式审批签章。
- 新项目 IT 容量与 CAPEX 从零开始，未录入前不生成现金流结论。租金、电价、PUE 等表单默认值仍是可编辑的**规划假设**，必须以报价与合同替换。项目机会列表初始为空，没有预置假项目。
- IT 上架率按首月到成熟值线性爬坡。托管收入 = 已上架 IT kW × 元/kW/月。GPU 收入 = 配置 GPU 数 × 元/小时 × 使用率 × 730 小时，再按已经投产的容量比例分配。混合模式按明确的 GPU 容量比例拆分托管与算力收入；自用模式单独录入可核验的替代收益。
- 每月电量 = 规划 IT MW × 上架率 × IT 负载率 × PUE × 730 小时。电价可填综合到户价，或由电能量、输配、线损、系统、基金、绿电与峰谷占比组成。峰谷倍率只施加于电能量部分。基本/需量电费单列。
- 分期 CAPEX 在投产前建设月份等额分摊；固定运维从投产开始计入。折旧、所得税及贷款按规划简化，项目现金流不受融资结构影响，股权现金流另计提款、本息及利息抵税。
- NPV 使用月度现金流按年折现率折现；IRR 是月度现金流求得的年化收益率。静态回收期是累计项目现金流首次转正的月份。
- 现有模型不包括增值税、完整税务亏损结转、设备逐项寿命与残值、季节性 PUE、逐时负载和电价、客户违约、价格指数、跨站迁移及网络成本。正式可研与投委会材料需由财务、工程、电力交易和法务校核。
- 落点初筛仅使用用户维护的场址实测时延、接入容量、已签约 IT 容量和到户电价。缺时延或接入容量的站点不会参与分配；结果尚未计入双运营商路径、网络费、数据驻留、合同可迁移条款及站点间可靠性耦合。
- “具备投决证据”只表示七项尽调均标记已核实、客户合同容量已录入、地址和接入容量完整、接入功率满足规划并且首期投产晚于预计接入。它不是系统替代审批的结论。
- 投决缺项还包含建设投资分项未核平、报价或估算依据缺失、测算期限未覆盖全部期次。未保存改动在项目切换和页面关闭时会提示。

## 后端接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/platform/planning/projects` | 查询已保存项目 |
| `GET /api/platform/planning/regions` | 查询省市级项目侧区域证据 |
| `POST /api/platform/planning/regions/import` | 批量导入区域证据；按省市、维度、指标、来源更新 |
| `POST /api/platform/planning/projects` | 创建项目，结构化字段校验 |
| `PUT /api/platform/planning/projects/{id}` | 按 revision 乐观锁更新 |
| `GET /api/platform/planning/projects/{id}/versions` | 查看历史输入版本 |
| `GET /api/platform/planning/projects/{id}/documents` | 查询附件及哈希 |
| `POST /api/platform/planning/projects/{id}/documents` | 上传附件，`gate` 与 `file` 表单字段 |
| `GET /api/platform/planning/projects/{id}/documents/{docId}` | 下载项目内附件 |

服务当前为本机原型，没有企业用户鉴权。对公网开放前必须先接入身份认证、角色权限及附件审计，并配置 HTTPS 与备份。
