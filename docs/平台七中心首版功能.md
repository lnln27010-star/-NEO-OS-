# 分布式算电协同平台七中心首版

本文记录首版的七中心设计及当时关闭入口的要求。当前的八中心入口和功能以 [NEO OS 功能架构适配说明](NEO-OS功能架构适配.md) 为准。

参考用户附件《分布式算电协同平台总体规划方案 v3》，采用全生命周期贯通、多站协同、算力和能源联合约束及人机协同的业务思路。沿用现有 React、Three.js 与 Zustand 项目，保留能源地图、园区、机房、设备建模、接线及运行仿真。

## 导航与标识

菜单依次为 AIDC资产中心、选址规划中心、工程设计中心、场景仿真中心、协同运营中心、智能运维中心、设备物联中心。原数字孪生设计器对应资产中心，原场景仿真对应场景仿真中心。新 Logo 将服务器机架、电力闪电和分布式节点组合为六边形标识，平台名称统一为分布式算电协同平台。建筑原有数据中心/AIDC 标识保留。

## 功能与联动

| 中心 | 已实现功能 | 业务联动 |
| --- | --- | --- |
| AIDC资产中心 | 原有能源地图、园区和机房建模，设备新增、移动、拆装、删除及端口接线 | 工程和运维可跳转到设备处理 |
| 选址规划中心 | 新增及编辑候选站点，容量、时延、面积硬约束，成本、容量、绿电、时延加权评分，JSON 评估导出 | 选用站点进入工程设计 |
| 工程设计中心 | 风冷/液冷占比、机柜规模、PUE、N+1/2N UPS 容量计算，站点/面积/现有设备容量校核，BOM、方案版本保存导出 | 调整现有资产或进入现有资产满载仿真 |
| 场景仿真中心 | 原有连续热模型、电量模型、故障推演、四流及时间轴 | 告警进入运维中心 |
| 协同运营中心 | 三站节点参数、24 小时负载分配、可迁移比例、光伏、购电功率限值、SOC 与充放电约束，时序图表、结果导出、策略本机保存 | 约束通过后可回放东部节点负载 |
| 智能运维中心 | 当前机柜和设施告警去重，创建工单，班组指派，接单、处理、复核、闭环，筛选和导出 | 定位到资产；告警存在时拒绝闭环 |
| 设备物联中心 | 当前模型设备搜索、功率/温度/流量/状态测点、MQTT/Modbus TCP/OPC UA 接入映射配置与导出 | 读取真实模型资产及当前仿真帧 |

## 参数与范围

候选站点容量、电价、绿电、时延和面积是可编辑的规划假设，不是已接入的现场数据或市场报价。评分采用用户权重归一化，硬约束不通过的方案不能进入选用流程。工程方案是估算方案，保存不会自动覆盖现有 3D 设备布局；满载校核明确针对当前资产。

协同调度采用小时步长，负载单位是等效 IT 功率 MW。固定负载按节点分配，可迁移负载按当小时电价×PUE 排序分配，受节点容量约束；缺额显式保留。光伏使用日间正弦出力假设，电价使用可编辑基准值与峰谷因子。储能充放电效率各 95%，初始 SOC 50%，最低 SOC 和功率可调。终端 SOC 与初始 SOC 差额按基准平均电价折算，避免把初始电量消耗计作免费收益。越限或未满足需求时禁用策略保存与仿真回放。此版没有连接实际跨站作业调度器、电力交易或站点储能控制器。

运维工单读取当前仿真帧，告警消除后才能复核闭环。物联模块只配置映射，现场网关明确显示待接入，不把仿真测点标为现场在线。业务方案、映射与工单存储于本机 aidc-platform-v1，未新增后端数据库、真实 MQTT/Modbus 网关、Agent 或第三方专业仿真引擎。

## 验证

运行 node scripts/test-centers.mjs，覆盖菜单、选址硬约束、权重、UPS N+1/2N 容量、需求和节点容量守恒、逐小时储能能量守恒、不可行调度、重复工单拦截、告警阻止闭环与本机持久化。保留原设备仿真、全球能源地图及资源交付回归。

浏览器验证：时延约束修改后站点排序和状态改变；站点选用进入工程设计；功率越限禁用保存与回放；PDU-C 故障形成 24 台设备告警；R-C01 工单进入待验证后活动告警阻止闭环，恢复正常工况后复核通过；物联搜索 CHWP 只显示 8 台泵并联动其流量。宽屏显示完整七中心菜单，窄桌面宽度折叠为图标菜单。

## 页面入口临时关闭

根据用户最新要求，选址规划中心、工程设计中心、协同运营中心、智能运维中心、设备物联中心暂时关闭页面入口。菜单名称和图标仍保留并置为不可点击；直接使用 center 查询参数也不能进入上述页面。AIDC资产中心与场景仿真中心继续开放。已有业务代码、方案、工单及映射数据保留，后续可通过 ENABLED_CENTERS 重新启用。
