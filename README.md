# 算电协同数字孪生生产级接入基线

开发前请先阅读 [AGENTS.md](AGENTS.md) 与 [智能体开发基线](docs/团队与智能体开发规范.md)。

## NEO OS 八大业务功能体系

依据总体规划和 NVIDIA DSX Blueprint 的场景交互方式，前台以现有全球能源网作为全域算电驾驶舱，园区和机房是同一数字孪生空间的下钻层级。基地资料与正式求解记录在全球场景内按需查看，不再单独打开静态地图驾驶舱。其他入口为规划与选址、设计与工程、仿真与验证、算电协同运营、智能运维、模型与能力。数据源和外部系统接入范围见 [功能架构适配说明](docs/NEO-OS功能架构适配.md) 和 [DSX 交互调研](docs/DSX交互调研与适配.md)。

专业工作中心的可执行工作流与资料限制见 [竞品调研与功能重构](docs/竞品工作流调研与功能重构.md)：站点准入、机柜 A/B 供电路径审计、正式优化数据准入、服务端设备工单和模型资料覆盖审计。

规划与选址中心默认进入[投前工作台](docs/规划选址与投资测算工作台.md)：[高德全国地图与分维度排名](docs/全国地图与排名口径.md)、项目开发漏斗、多客户需求、场址尽调及附件、技术方案比选、[IDC 工作簿投资测算](docs/IDC工作簿投资测算适配.md)和组合决策；[功能对照](docs/规划与选址功能对照.md)列出与业务清单的对应关系。省级参考数据的判读限制见[全国选址数据与判读边界](docs/全国选址数据与判读边界.md)。

## 基本信息与运营维护

场景栏“基本信息”按中心组织基础档案、服务器/部件、图纸与清册导入、配置变更、运行测点、工况电价和版本审计。采用草稿 r、配置 c、生效基线 B 分层维护，正式求解读取已发布基线。支持 IFC、DXF、PDF 文字/规则表格、XLSX/CSV 和 Redfish 离线快照的候选提取、字段映射和差异审核。扫描图和 DWG 留存原件，不冒充自动建模。详情见 [基本信息运营维护](docs/基本信息运营维护.md)。

## v7 工程仿真升级

场景仿真中心新增四引擎工程求解工作台、独立任务服务、计算记录、日志、算例导出、结果文件及三维结果图层。pandapower 与 PyPSA/HiGHS 已在本机完成真实求解；OpenFOAM 与 FEniCSx 提供生成器、执行适配器和固定版本容器配置，本机还没有就绪的 Linux/Docker 环境，界面显示待配置，不返回替代计算结果。

首次安装运行 `scripts/setup-simulation.ps1`。启动运行 `scripts/start-platform.ps1`，或双击 `启动算电协同.cmd`，将同时启动前端与求解服务。已有 Docker Linux 容器环境时，运行 `scripts/setup-simulation.ps1 -Containers` 构建另外两个引擎镜像。

智能体通过 `backend.mcp_server` 调用与浏览器相同的任务服务，支持环境检查、读取模型、提交、导出算例、查询、取消及读取结果文件。详情见 [专业仿真引擎接入](docs/专业仿真引擎接入.md)。

这是一版面向数据中心设计期的可运行原型和生产级真实资产接入基线。当前重点验证空间下钻、三维机房搭建、设备拖放、工程属性和分析结果的交互方式；园区与设备在接入业主 BIM/点云/厂商资产前，明确标记为合成示例，不冒充真实项目。

原型现在覆盖三个空间层级：江苏省域真实行政边界、合成但按真实尺度组织的数据中心园区，以及可编辑的液冷机房内部。三层通过顶部“省域 / 园区 / 机房”切换并逐级下钻。

## 本地运行

Windows 用户可以直接双击项目根目录的 `启动算电协同.cmd`。
该入口先构建优化版，再启动预览服务；页面使用压缩资源和按场景拆分的代码。修改代码时，可用下面的开发模式命令。

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:4186/`。副本使用固定端口，避免打开另一份项目的旧实例。

## 生产构建

```bash
npm run build
```

## 主要操作

- 使用顶部“省域 / 园区 / 机房”切换空间层级
- 在省域左侧城市列表选择城市；南京市提供合成园区下钻入口
- 在园区选择数据楼或能源设施；A2 液冷数据楼可继续进入机房
- 从左侧资产卡拖入三维场景
- 无法拖拽时，点击资产卡右下角的“添加”自动放到最近可用网格
- 左键选择设备，拖动已选设备调整位置
- 右键旋转视图，滚轮缩放
- 拖入或移动时查看维护区、碰撞和边界反馈
- 按 `R` 将放置预览或所选设备旋转 90 度
- 按 `Esc` 取消当前放置
- 按 `Delete` 删除选中设备
- 按 `Ctrl+D` 复制选中设备
- 按 `Ctrl+Z` 撤销操作
- 按 `Ctrl+K` 聚焦资产搜索
- 点击问题表中的记录定位对象

## 原型边界

当前参数与校核结果用于交互验证，尚未接入真实厂商数据、BIM、专业 CFD、电气求解器或现场遥测。进入真实项目试点前，需要用样板机房数据和工程计算表完成模型标定。

园区建筑、设施、状态和坐标布局均为合成建模示例，不代表真实项目。江苏省域边界数据来自阿里云 DataV 的离线 GeoJSON，仅用于内部原型。面向社会公开发布前，应以江苏省自然资源厅标准地图为依据，并按最终三维地图成品完成地图审核和审图号标注。详见 `public/data/README.md`。

## 四厅参考布局与四流仿真 v3

进入新版机房，默认启用俯视布局和直接拖动。384 个 42U 机柜分成两个风冷厅、两个液冷背板厅，默认满配 7680 台服务器；540 个设备和主管节点覆盖变压器、低压柜、UPS、电池、精密空调、PDU、CDU、冷水机组、两类水泵与室外设备。支持主体拖动、密排机柜交换、设备库拖入安装、服务器移装、额定参数修改及四类流动展示。

调研依据、布局、操作说明和计算假设见 [数据中心参考布局与四流仿真](docs/数据中心参考布局与四流仿真.md)。本版为依据真实设计原则建立的参考方案，未代替业主竣工 BIM、现场遥测或工程 CFD。
