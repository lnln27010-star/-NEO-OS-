# 江苏省边界原型数据

`jiangsu-cities.geojson` 于 2026-09-23 从阿里云 DataV 行政区划边界接口下载，接口地址为：

`https://geo.datav.aliyun.com/areas_v3/bound/320000_full.json`

文件只用于本项目内部交互原型，提供江苏省 13 个设区市的离线边界、名称和中心点。它不是带审图号的正式地图产品，不能直接作为公开商业地图发布。

公开发布前应以[江苏省自然资源厅标准地图服务](https://zrzy.jiangsu.gov.cn/jsbzdt/index.html)为制图依据，并按最终三维化、标注和场址点位后的成品办理地图审核和审图号标注。

`jiangsu-satellite.jpg` 和 `nanjing-industrial-tile.jpg` 是 ArcGIS World Imagery 的视觉参考底图，用来校准真实场地的色调、尺度和地理阅读方式；它们不代表本项目拥有对应场址的测绘授权，也不能替代业主正射影像、DEM 或审图合规底图。
